# Scout

Scout is a local-first discovery engine that turns bounded, attributable observations into fact-locked decisions and at most three concise cards per manual run.

This repository is the sanitized public source for Scout code and documentation. Personal profiles, collected observations, cards, feedback, checkpoints, source state, caches, and run history belong outside Git under `~/.local/state/scout/`.

The initial `main` commit is intentionally minimal. The reviewed MVP implementation is prepared on branch `mvp-v1` and will enter `main` through the normal pull-request workflow.
